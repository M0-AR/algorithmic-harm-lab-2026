✨ Features — everything included

📖 Theory as code

Closed-form monopoly, perfect/imperfect discrimination, BBP appendix algebra, targeting thresholds — all asserted to 1e-9.

🤖 Coordination simulator

Tabular Q-learning Bertrand duopoly with collusion index vs Nash baseline. Seed-sensitive distribution warning built in.

🔍 Fairness + transparency suite

Random-forest blackbox → permutation + LASSO + teacher-student tree + OLS disparate-impact with controls. Proves single-protocol audits miss leakage.

🌐 Live market bridge

Keyless fetches (housing REIT, ECB FX, FTC PDF, SEC filings) with 429 backoff + logged fallback. Never silent.

🕵️ 5 hidden patterns

Mild-bias blind spot, BBP flip, collusion variance, proxy inconsistency, slow rent decay — each with follow-up study.

📦 One-command reproduce

Docker Compose (lab/jupyter/verify), Makefile, pinned requirements, config.yaml, CI-ready pytest.

🚀 Quickstart (3 commands)

git clone <this-repo> && cd algorithmic-harm-lab-2026
docker compose up --build lab
# open results/*.json + *.png — or:
pip install -r requirements.txt && PYTHONPATH=. python experiments/run_all.py --seed 42 --live
PYTHONPATH=. pytest -q tests/

Config: see config.yaml (V, cost, biases, Q-learning params, live URLs). Structure: src/ theory · experiments/ 6 studies · results/ outputs · assets/ README visuals · data/README.md live-source log · papers/ PhD outline.

❓ FAQ
